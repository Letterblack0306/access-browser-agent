## 2. TIMEOUT ENFORCEMENT (FIX #P4)

### Configuration:
- **Default**: `DEFAULT_RUN_TIMEOUT_MS = 30 * 60 * 1000` = **30 minutes** (line 12)
- **Configurable**: Passed via constructor, default 30min (line 15)
- **Disabled**: Set `runTimeoutMs = 0` to disable timeout checks

### How it Works:
1. Constructor sets `this.runTimeoutMs = Math.max(0, Number(runTimeoutMs) || 0)` (line 27)
2. `_runDeadline = this.runTimeoutMs > 0 ? Date.now() + this.runTimeoutMs : null` (line 93)
3. At top of each loop iteration: `if (Date.now() >= this._runDeadline) ... forceTimeout()` (lines 213-222)
4. `forceTimeout()` persists `objective.timed_out` and halts loop durably (lines 137-158)

**RESULT:** Loop CANNOT execute indefinitely. Maximum runtime = configured timeout (default 30min).
